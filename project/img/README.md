# Project figures

Figures are generated in R by `scripts/visualisations.R` and `scripts/analysis.R`.

- `fig-01-demand-heatmap.png`: the main annual date-by-hour demand heatmap.
- `fig-02-hourly-profiles.png`: seasonal hourly profiles by working-day status.
- `fig-03-weather-demand.png`: supporting descriptive weather comparison.
- `04_validation_rmse.png`, `06_test_hourly_bias.png`, `07_test_week.png`: model evaluation diagnostics used in the investigation.

The report uses two complementary figures. The presentation uses the same evidence. Unused example photographs from the teacher template remain available in the original-template commit.
